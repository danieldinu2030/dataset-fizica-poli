# Subiecte Dataset Fizica

## Conținut 

- fișierele `.tex` asociate chestionarelor de concurs pentru admitere/simulare/preadmitere incluse

## Formatul unei linii de cod LaTeX pentru exerciții:

- `<an>.<cod_proba>.<nr_ex>. <text_ex>\\ a) var1; b) var2; c) var3; d) var4; e) var5; f) var6.\\ <figura_optionala>\\ <rezolvare> Răspuns corect <raspuns>.\\`
- formatul include cu exactitate și whitespace-uri, pentru verificare și extragere mai ușoară a informațiilor
- formatul liniilor fișierelor se poate testa cu un script-ul `check_format.py`
